# DeepSeek 网页增强（浏览器扩展）

给 [chat.deepseek.com](https://chat.deepseek.com) 做**纯原生页面底层增强**：关闭虚拟列表卸载、流式防抢滚、原生宽屏排版、思维链折叠、`\[...\]` 公式兼容渲染、公式源码复制，并顺手修掉官方的两个老毛病（左下角「请检查浏览器插件」弹窗、`removeChild` 触发的「页面崩溃」页）。

Manifest V3，Edge / Chrome 通用，不需要构建，直接「加载解压缩的扩展」即可。

**没有覆盖页、没有浮层、没有重绘的对话界面** —— 你看到和操作的始终是 DeepSeek 原版页面，上传图片/文件、分支切换、深度思考、智能搜索、右侧段落导航全部原封不动。

---

## 功能

### 1. 关闭虚拟列表卸载（全量静态渲染）

DeepSeek 的消息列表用的是自制虚拟滚动：预估高度按 140px 算，实际长文动辄上万像素，于是你一滚它就销毁重建 DOM、改 `translateY` 补偿，结果就是**掉帧、闪烁、滚动条抽搐、`Ctrl+F` 搜不到上文**。

插件直接复用 DeepSeek 自己内置的 `virtual = false` 通路（它原本用于打印），在会话加载/切换/新消息时自动把列表切成全量静态渲染：

- 当前会话所有消息常驻 DOM，不再随滚动卸载；
- 滚动位置做锚定补偿，切换瞬间不跳；
- 顺带让浏览器自带的页内查找 `Ctrl+F` 能搜到整篇对话。

### 2. 流式生成「防抢滚」

DeepSeek 在生成回答时会持续 `scrollTo` 把视图吸到底部。插件在页面主世界劫持了 `.ds-virtual-list` 上的程序化滚动：**当你主动向上滚读上文时，它的吸底拉拽会被拦掉**；等你滚回底部、点击右侧导航或按回车发送，就自动恢复跟随。

### 3. 原生宽屏排版

直接接管 DeepSeek 自己的 CSS 变量 `--message-list-max-width`，右上角小胶囊可一键循环 **标准 800px / 宽屏 980px / 超宽 1180px**，小窗口下自动回落到可用宽度；超长块级公式与代码块允许横向滚动，不撑破正文。

### 4. 思维链（深度思考）折叠

- **默认收起**：打开对话页时，已经思考完的块自动折叠成一行「已思考（用时 N 秒）」。
- **生成完成自动收起**：思考过程中保持展开，正文开始输出时自动折叠。
- **记住每条的展开状态**：手动展开/折叠过的，刷新后保持一致。
- **一键全部折叠 / 展开**：右上角胶囊或面板按钮。
- 折叠用属性 + CSS 在原帧定型，不事后点 React 改高度，翻历史不跳。

### 5. LaTeX 兼容渲染（含官方解析 Bug 的修复）

DeepSeek 只认 `$...$` 和 `$$...$$`。从论文、ChatGPT 复制来的 `\[ ... \]`、`\( ... \)` 会被当普通文字显示。

更麻烦的是官方 Markdown 解析器在**列表项缩进的块级公式**上会翻车：把开头的 `\[` 吞掉、把矩阵换行 `\\` 转义成单反斜杠、再在尾巴上留一个孤立的 `]`，于是整篇矩阵和证明全部源码外露。

插件会：

- 识别「公式文本 + `<br>` + 孤立 `]`」这种被拆碎的块，重组成标准块级公式居中渲染，**后面的中文注释原样保留在公式下方**；
- 自动修复被吃掉的矩阵换行（`matrix` / `pmatrix` / `bmatrix` / `cases` / `aligned` 等环境内）与分块矩阵的 `\,` 小空格；
- 纯文本括号（如 `[注]`、`(见上)`、`[1]`）不会被误伤；
- 行内按行内渲染，整段一个公式时按块级居中渲染。

### 6. 复制公式得到完整 LaTeX

选中公式任意片段（哪怕只框住一半或某个上标）按 `Ctrl/Cmd+C`，剪贴板里就是整个公式的完整 LaTeX 源码：

- 行内输出 `$...$`，块级输出 `$$ ... $$`（面板里可关掉定界符只要裸源码）；
- 同时选中正文和公式时，正文照常复制，公式替换成源码；
- 一次选中多个公式时，每个都输出完整源码。

### 7. 修掉官方的两个老毛病

- **左下角「请检查浏览器插件」弹窗**：官方会把遥测上报（`/api/v0/telemetry`）连续失败 3 次当成「被广告拦截插件拦了」。插件在主世界劫持 `fetch`，让这类请求直接本地返回 `200`，不再撞 uBlock Origin，弹窗从源头消失（CSS 再兜一层）。
- **「页面崩溃可能与浏览器插件对页面内容的修改有关」**：官方用 `/Failed to execute '(insertBefore|removeChild)' on 'Node'/` 判定插件改坏了 DOM 并整页重置。插件做了两件事：修复公式时**只原地隐藏、绝不删除 React 持有的节点**；同时给 `Node.prototype.removeChild / insertBefore` 加父节点校验，缺节点时静默降级而不抛异常。

## 安装

1. 下载本目录（`deepseek-toolkit`）。
2. 打开 `edge://extensions/`（Chrome 为 `chrome://extensions/`）。
3. 打开「开发人员模式」。
4. 点击「加载解压缩的扩展」，选择 `deepseek-toolkit` 文件夹。
5. 打开 https://chat.deepseek.com 并刷新一次即可。

> 改了代码后，在扩展管理页点「重新加载」，再刷新 DeepSeek 页面。

---

## 使用提示

- 面板里所有开关**即时生效**，不需要刷新页面。
- 右上角胶囊：`全量渲染 · N条`（点击可确认状态）、宽度切换、收起/展开思考。
- 想回到原生虚拟列表，把面板里的「关闭虚拟列表卸载」关掉即可。
- 插件不改动 DeepSeek 的任何账号设置，也不上传数据；所有配置只存在本机扩展存储里。

## 目录

```
deepseek-toolkit/
├── manifest.json
├── main-world.js     # 页面主世界：防崩溃护盾 / 遥测拦截 / 防抢滚 / 切换全量渲染
├── content.js        # 静态渲染守护 + 思维链折叠 + 公式修复渲染 + 复制拦截
├── content.css       # 宽屏变量 + 公式样式 + 胶囊 UI
├── popup.html/css/js # 开关面板
├── vendor/           # KaTeX（含字体，用于重新渲染公式）
└── icons/
```

## 已知限制

- 公式兼容主要针对 `\[...\]`、`\(...\)` 与被官方解析器拆碎的块级公式；`$...$`、`$$...$$` 本来就能正常渲染，不做改动。
- 公式里嵌套中文字符等歧义写法，为了保证不误伤正文会保持原样。
- DeepSeek 前端改版后，思维链标题条与虚拟列表的类名可能变化，届时需要更新识别规则。
