# DeepSeek 网页增强（浏览器扩展）

给 [chat.deepseek.com](https://chat.deepseek.com) 加三件事：**思维链自动收起**、**`\[...\]` / `\(...\)` 公式正常渲染**、**复制公式得到完整 LaTeX 源码**。

Manifest V3，Edge / Chrome 通用，不需要构建，直接「加载解压缩的扩展」即可。

---

## 功能

### 1. 思维链（深度思考）折叠

- **默认收起**：打开对话页时，已经思考完的块自动折叠成一行「已思考（用时 N 秒）」。
- **生成完成自动收起**：思考过程中保持展开，正文开始输出时自动折叠。
- **记住每条的展开状态**：你手动展开某一条，刷新页面后它仍然是展开的；手动折叠的同理。
- **全部折叠 / 全部展开**：面板上两个按钮，一键处理当前页所有思维链块。
- **翻历史时也能自动折叠**：新消息挂载的同一帧里就用 CSS 把已完成的思考块定成折叠态（不靠事后再点 React），不会在排版之后改变高度，画面不跳。

### 2. LaTeX 公式兼容

DeepSeek 只认 `$...$` 和 `$$...$$`。从论文、ChatGPT 或其它地方复制来的 `\[ ... \]`、`\( ... \)` 会被当成普通文字，显示成 `[ ... ]`、`( ... )`。

插件会识别这种“内容里带 `\frac`、`\alpha` 之类 LaTeX 命令的括号文本”，用自带 KaTeX 原地重新渲染成正常公式：

- 纯文本括号（如 `[注]`、`(见上)`、`[1]`）不会被误伤；
- 模型只写了结尾 `\]`、或者整段就是裸 LaTeX（没有任何括号）时，也会按“整段公式”渲染，并隐藏旁边孤立的 `[` / `]` 行；
- 整段就是一个公式时按块级公式居中渲染，行内的按行内渲染；
- 超宽公式横向滚动，不会撑破页面；
- 正在流式输出时也会跟着渲染，输出完自动补正。

### 3. 复制公式得到完整 LaTeX

DeepSeek 的公式是一堆嵌套 `<span>`，直接选中复制会得到一堆错乱的符号。

装上插件后：**选中公式的任意片段（哪怕只框住一半，或者只选到某个上标），按 Ctrl/Cmd+C，剪贴板里就是整个公式的完整 LaTeX 源码**。

- 行内公式复制为 `$...$`，块级公式复制为 `$$ ... $$`（可在面板里关掉定界符，只要裸源码）；
- 同时选中正文和公式时，正文照常复制，公式部分替换成对应的 LaTeX；
- 一次选中多个公式时，每个公式都输出完整源码。

## 安装

1. 下载本目录（`deepseek-toolkit`）。
2. 打开 `edge://extensions/`（Chrome 为 `chrome://extensions/`）。
3. 打开「开发人员模式」。
4. 点击「加载解压缩的扩展」，选择 `deepseek-toolkit` 文件夹。
5. 打开 https://chat.deepseek.com 并刷新一次即可。

> 改了代码后，在扩展管理页点「重新加载」，再刷新 DeepSeek 页面。

---

## 使用提示

- 面板里所有开关**即时生效**，不需要刷新页面。
- 「全部折叠 / 全部展开」只作用于当前打开的对话页。
- 插件不改动 DeepSeek 的任何设置，也不会上传数据；所有配置只存在本机扩展存储里。
- 如果某条消息很长、公式很多，首次渲染可能有一瞬间的“原文 → 公式”切换，属于正常现象。


## 已知限制

- 只处理 `\[...\]`、`\(...\)` 这两种“被转义成普通括号”的写法；`$...$`、`$$...$$` 本来就能正常渲染，不做改动。
- 少见的写法（例如公式里嵌套中文字符）为了保证不误伤正文，会保持原样不转换。
- DeepSeek 前端改版后，思维链标题条的类名/结构可能变化，届时需要更新识别规则。
